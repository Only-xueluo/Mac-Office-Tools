# Mac Office Tools

macOS 菜单栏工具。点击菜单栏中的文档图标，可按 **Word**、**Excel**、**PowerPoint** 分组查看当前窗口标题；没有打开文件的应用不会显示。点击标题即可将对应窗口前置，每个分组顶部还可新建文档或工作簿。

每个已打开的文件行右侧都有复制按钮，位于关闭叉号左侧。点击即可将该行对应的已保存 Word、Excel 或 PowerPoint 文件作为文件对象复制到 macOS 剪贴板；切换到聊天框后按 **⌘V** 即可粘贴附件。复制成功、未保存和失败都会显示短暂提示。

## 隐私与权限

程序仅通过 macOS“辅助功能”接口读取窗口标题、恢复最小化窗口并将窗口前置；不会读取、修改或保存 Office 文档内容。点击复制按钮时，程序会请求 macOS 的“自动化”权限，用于取得已保存 Office 文件的位置。

首次启动时，程序会显示权限说明，并可直接打开“系统设置 → 隐私与安全性 → 辅助功能”。启用“Mac Office Tools”后，菜单栏图标即可列出 Office 窗口；首次点击复制按钮时，请允许其控制 Microsoft Excel、Word 或 PowerPoint。

## 构建

在此目录运行：

```zsh
zsh build.sh
```

构建脚本不会覆盖现有的同版本交付物。新版本应先调整 `Info.plist` 和 `build.sh` 中的版本号，再重新构建。
